# 目标执行与 fallback

`probes/` 已包含 WB-01 最小 HIP 设备探测器；尚无通用 GPU runner 或保证正确的设备 fallback。
探测器的用法、证据和退出状态见 [`probes/README.md`](probes/README.md)。

计划的执行协议：

1. 固定 ROCm、编译器、驱动、设备 PCI/逻辑 ID、GCD 身份和可见设备配置。
2. 编译最小能力探针，从实际代码和运行行为核实波宽、intrinsic 与掩码语义；不根据 GPU 名称直接推断。
3. 记录源和目标程序、完整 launch、编译命令及二进制哈希。
4. 按外部数值协议执行正确性测试和可用的运行时检查。
5. 排除检查失败的候选后，再进行 warmup、事件计时、同步和重复采样。
6. 对 fallback 同样记录目标、输入域和正确性证据；失败或未知时拒绝部署。

W7900 普通 wave32 探针已在本机建立一致的编译元数据与运行证据，详见 `docs/status.md`。
MI250、W7900 同卡 wave64 尚未验证。多个 GCD 分别记录，但架构多样性只按实际架构统计。
