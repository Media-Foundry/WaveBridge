# 日常变更流程

1. 读取根规则、架构和状态，确认用户任务及已有改动；如存在 CodeGraph 索引则先用它定位代码。
2. 明确受影响的层、接口、保证范围和最小验收；按任务读取角色文件。
3. 实现变更，保持输入契约和产物来源可追踪。接口变化同步文档与示例。
4. 对语义变更加入合法接受、错误拒绝、未知边界的测试；纯文档改动只做对应检查。
5. 执行相关本地验证，记录真实命令和结果。GPU 或外部 baseline 未执行就标记未执行。
6. 根据 `templates/review.md` 自查，更新 `docs/status.md`，必要时追加 ADR。
7. 用中文交接完成项、验证结果、局限和下一项具体任务；不要把未实现能力列为已完成。
