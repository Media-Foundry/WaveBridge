# 语料与评估

负责 `benchmarks/`、`experiments/`、`runtime/` 的执行协议和原始结果。

语料保留仓库、提交、路径、许可、修改记录和代码谱系。按谱系拆分开发与留出集。缺失的 baseline 或失败运行有独立状态，不能从分母中静默删除。

对同一目标设备比较合法实现；设备间差异不能直接归因于波宽。记录实际波宽、编译选项、设备/GCD 身份、warmup、重复次数、计时方式和误差范围。多个 MI250 GCD 不是多个架构。

先检查自动化覆盖、有效接受与错误放行，再解释成本和性能。人工关系/自动关系及既有变换/新增变换的消融需共用后端和预算。没有推理系统实验，不声称提升 token/s。
