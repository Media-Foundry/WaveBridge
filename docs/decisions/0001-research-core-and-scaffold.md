# ADR 0001：研究核心、实现分层与参考模型

状态：已采纳用于仓库脚手架；编译器技术栈尚待实验决策。

## 背景

用户提案将候选创新定位于跨 lane 关系恢复与检查。兼容模式、普通重新分工、kernel/launch 联动、布局抽象和候选搜索分别已有相关工作，不能仅靠模块组合宣称创新。

## 决策

采用 Python 单包组织协议、编排和参考语义；预留 `compiler/` 接入真实 Clang/LLVM 分析及变换，`runtime/` 接入目标执行。checker 与候选生成器独立。先用量化点积的固定形状无界整数模型验证边界与拒绝路径。

协作宽度、量化分组、归约路由宽度、遍历步长和 launch 分别表示；这种冗余用于暴露错误耦合。暂不冻结通用关系 IR，不引入求解器、MLIR 依赖或 agent 生成后端。

## 影响与重新评估条件

CPU 可独立开发和回归，但结果不保证 HIP/CUDA 语义。整数重排不覆盖浮点重排。真实 kernel 案例和最接近工作对照完成后，重新评估 IR、编译基础设施和求解策略；记录后续 ADR。
